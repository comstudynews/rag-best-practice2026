# RAG 평가 결과 예시

## 테스트 데이터셋

총 10개 질문으로 구성한다.

- 명확한 정답 질문
- 표현 변경 질문
- 키워드 중심 질문
- 복합 질문
- 문서에 없는 질문

## 평가 결과 예시

| 질문 | Baseline | 개선 결과 |
|---|---|---|
| 제품 설치 방법 | 관련 문서 검색 실패 | 정확한 문서 검색 |
| 오류 코드 문의 | 유사 문서 반환 | Hybrid Search로 개선 |
| 문서 외 질문 | 잘못된 답변 생성 | 근거 없음 응답 |

## 분석

개선 전략 적용 후 일부 질문의 검색 품질이 향상되었다.

그러나 모든 질문이 개선되는 것은 아니며, 데이터셋 품질과 문서 구조가 결과에 영향을 준다.
