# AsterDesk 설치 가이드

## Windows

AsterDesk Desktop의 Windows 지원 버전은 Windows 11 22H2 이상이다.
설치 전에 최소 8GB RAM과 5GB 이상의 여유 디스크 공간을 확인한다.

설치 절차는 다음과 같다.

1. AsterDesk 설치 패키지 `AsterDeskSetup.exe`를 실행한다.
2. 설치 경로를 선택한다.
3. 조직에서 발급한 Workspace ID를 입력한다.
4. 설치 완료 후 AsterDesk를 실행한다.
5. 최초 로그인 후 장치 등록을 완료한다.

Windows 기본 설치 경로는 `C:\Program Files\AsterDesk\`이다.

## macOS

macOS 14 이상을 지원한다.
설치 파일 `AsterDesk.dmg`를 열고 AsterDesk를 Applications 폴더로 이동한다.
