# DEMO-RAG-2026 설치 가이드

이 문서의 제품명과 경로는 교육용 가상 예시입니다.

## Windows

DEMO-RAG-2026 Desktop의 Windows 지원 버전은 Windows 11 22H2 이상이다.
설치 전에 최소 8GB RAM과 5GB 이상의 여유 디스크 공간을 확인한다.

설치 절차:

1. 설치 패키지 `DemoRAGSetup.exe`를 실행한다.
2. 설치 경로를 선택한다.
3. 조직에서 발급한 Workspace ID를 입력한다.
4. 설치 완료 후 DEMO-RAG-2026을 실행한다.
5. 최초 로그인 후 장치 등록을 완료한다.

Windows 기본 설치 경로는 `C:\Program Files\DemoRAG2026\`이다.

## macOS

macOS 14 이상을 지원한다.
설치 파일 `DemoRAG2026.dmg`를 열고 애플리케이션을 Applications 폴더로 이동한다.
