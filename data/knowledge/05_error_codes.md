# DEMO-RAG-2026 오류 코드

## ERR-AUTH-017

의미: 로그인 토큰이 만료되었거나 유효하지 않다.

조치:

1. 로그아웃한다.
2. 애플리케이션을 완전히 종료한다.
3. 다시 실행한 뒤 로그인한다.
4. 동일 오류가 계속되면 시스템 시간을 확인한다.

## ERR-NET-403

의미: 인증 서버 연결 실패.

조치:
네트워크 요구사항 문서의 DNS, TCP 443, 프록시, 방화벽 순서로 확인한다.

## ERR-SYNC-221

의미: 동기화 충돌이 감지되었다.

조치:
로컬 변경 파일을 백업한 뒤 충돌 해결 화면에서 서버 버전과 로컬 버전을 비교한다.
