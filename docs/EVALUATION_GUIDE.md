# 평가 데이터셋 및 RAG 평가 가이드

## 1. 질문 개수보다 중요한 것

평가 질문이 많을수록 일반적으로 안정적인 평가에 도움이 되지만, 단순히 비슷한 질문을 반복해 개수만 늘리는 것은 의미가 없습니다.

중요한 요소는 다음과 같습니다.

- 실제 사용 질문을 대표하는가?
- 난이도와 질문 유형이 다양한가?
- 정답 문서가 명확한가?
- 문서에 답이 없는 질문이 포함되어 있는가?
- 실제 실패 사례가 포함되어 있는가?

## 2. AI를 이용한 평가셋 확장

AI를 이용해 질문을 확장할 수 있습니다.

권장 흐름:

```text
Human Seed Questions
      ↓
AI Paraphrase / Variation
      ↓
Human Review
      ↓
Deduplication
      ↓
Gold Test Set
```

AI가 만든 질문을 검수 없이 바로 Gold Set에 포함하지 않습니다.

검수 항목:

- 질문의 의미가 원문과 유지되는가?
- 정답 문서가 동일한가?
- 질문이 지나치게 쉬워지거나 어려워지지 않았는가?
- 원문과 사실상 동일한 중복 질문은 아닌가?
- 답을 질문에 포함시키고 있지는 않은가?

## 3. Retrieval 평가

### Hit Rate@K

정답 문서가 Top-K에 포함되었는지 확인합니다.

### MRR@K

정답 문서가 상위에 검색될수록 높은 점수를 부여합니다.

```text
rank 1 → 1.0
rank 2 → 0.5
rank 3 → 0.333...
MISS   → 0
```

## 4. Generation 평가

확인 항목:

- 검색 Context와 답변이 일치하는가?
- 질문에 직접 답하는가?
- 근거 없는 내용을 생성하지 않는가?
- 문서에 답이 없을 때 답변을 제한하는가?
- 근거 문서 ID를 표시하는가?

## 5. 결과 해석

개선 후 모든 지표가 상승해야 하는 것은 아닙니다.

예:

- 정확 키워드 검색은 개선됨
- 의미 검색은 일부 질문에서 동일
- Hybrid 가중치 때문에 특정 질문 순위는 하락

이러한 결과도 Trade-off로 기록합니다.
